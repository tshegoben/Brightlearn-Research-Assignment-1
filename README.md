# Data Analytics & Data Science – Research Assignment 1

## Overview

This repository contains my **Data Analytics & Data Science Research Assignment 1**, completed as part of my studies with BrightLearn.

The assignment focuses on building a foundational understanding of **data, artificial intelligence, machine learning, APIs, Python, data privacy, ethics, governance, and business intelligence**.

The research was completed using online resources and presented in my own words, with sources referenced throughout the assignment.

## Topics Covered

### Section A – Data Concepts

* Data storage formats
* Structured and unstructured data
* Data management concepts

### Section B – Artificial Intelligence & Machine Learning

* Artificial Intelligence (AI)
* Machine Learning (ML)
* Deep Learning
* Natural Language Processing (NLP)
* Large Language Models (LLMs)
* Generative AI
* Training data
* Computer Vision

### Section C – APIs & Developer Concepts

* Application Programming Interfaces (APIs)
* API keys and security
* REST APIs

* Prompt Engineering

### Section D – Data Privacy, Ethics & Business Intelligence

* Data privacy and GDPR
* Data ethics
* Data governance
* AI bias
* Data-related career roles
* Business Intelligence (BI)
* Data visualisation and dashboards

## Learning Objectives

Through this assignment, I developed a better understanding of:

* How data is stored and processed.
* The differences between AI, ML and Deep Learning.
* How modern AI technologies such as LLMs and Generative AI work at a foundational level.
* How APIs allow different software systems to communicate.
* The role of Python and its libraries in data analysis.
* The importance of data privacy, ethics and governance.
* How bias can affect AI systems and their outcomes.
* Different career paths within the data and AI field.
* How Business Intelligence can help organisations make data-driven decisions.
